# Pi

- `scripts/pi-extension.ts` is a default-export factory, and `scripts/pi-adapter.ts` maps Pi session entries onto the shared `core.ts` and `runHook` pipeline. The first `before_agent_start` injects the preamble once per session, `turn_end` runs the live monitor with `deliverAs: "steer"`, and `agent_end` runs the stop check: a block goes out as `followUp` with `triggerTurn` under a `blockCount` guard reset on user `input` and `session_start`, and a nudge as `nextTurn`
- Pi never calls the `SessionStart` handler: `before_agent_start` injects the preamble instead, and a session review breaker marker on Pi lives until the tmpdir is cleared; see [[reviewer]]
- The Pi extension import of `@earendil-works/pi-coding-agent` is type-only. Once `package.json` has a `pi` manifest, Pi skips its default `skills/` scan, so a new skill is a directory under `skills/` and nothing else, because `pi.skills` already points there
- Pi appends skill arguments after the skill body and does not substitute `$ARGUMENTS`, while Claude Code appends `ARGUMENTS: <args>` when no placeholder is present, so `skills/actually/SKILL.md` carries no `$ARGUMENTS` placeholder and both hosts deliver the correction text the same way
- `ctx.sessionManager.getSessionFile()` returns `string | undefined`, so every Pi hook input site that sends `transcript_path` (the taste `input` handler and `agent_end`) passes it through and leaves the key absent when Pi has no session file. Never add `?? ""`: `HookInputSchema` accepts an empty string as a real path and the reviewer receives a bogus `transcript_path` [source: https://github.com/correctionguy/correctionguy/issues/43]
- Pi's `loadSkillsFromDir` takes a skill's name from the `SKILL.md` frontmatter `name`, falls back to the directory name when `name` is missing or not a string, and checks only the name format; `claude plugin validate --strict` compares no name either. The name-versus-directory check in `scripts/validate.ts` is the only guard, so never delete it as redundant. A `SKILL.md` without `name` passes it, and closing that gap needs an explicit `name` requirement [source: https://github.com/correctionguy/correctionguy/pull/55]
